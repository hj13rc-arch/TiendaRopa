TiendaRopa

Sistema de escritorio para registrar ventas, administrar clientes y productos, y consultar el inventario de una tienda de ropa. Desarrollado con C# Windows Forms y SQL Server.

Ver prototipo en Figma Ver código en GitHub

Módulos del sistema

Seguridad

Inicio de sesión con roles de administrador y cajero.

Productos

Gestión del catálogo por código, talla y color, con precios y existencias.

Clientes

Registro, edición y búsqueda por nombre o teléfono.

Ventas

Registro de varias prendas en una venta y actualización de existencias al confirmarla.

Reportes

Consulta del historial de ventas, comprobantes e inventario.
